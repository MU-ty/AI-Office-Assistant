## 🔐 认证与授权的核心概念

### 用户认证流程

```
用户提交用户名/密码
          ↓
FastAPI 验证凭证
          ↓
PostgreSQL 查询用户
          ↓
bcrypt 验证密码哈希
          ↓
生成 JWT Token (Access + Refresh)
          ↓
返回 Token 给客户端
          ↓
客户端保存 Token (localStorage)
          ↓
后续请求在 Authorization 头中携带 Token
          ↓
FastAPI 验证 Token 合法性
```

### Token 类型设计

#### Access Token (访问令牌)

- **用途**: API 请求身份验证
- **有效期**: 15-30 分钟
- **存储**: localStorage (前端)
- **传输**: `Authorization: Bearer <token>`

```json
{
  "sub": "user-id", // 用户 UUID
  "username": "john_doe",
  "exp": 1704067200, // 过期时间戳
  "iat": 1704063600, // 签发时间戳
  "type": "access"
}
```

#### Refresh Token (刷新令牌)

- **用途**: 在 Access Token 过期时获取新的 Access Token
- **有效期**: 7 天
- **存储**: localStorage 或 HttpOnly Cookie
- **传输**: 请求体中

```json
{
  "sub": "user-id",
  "username": "john_doe",
  "exp": 1704672000, // 7 天后过期
  "iat": 1704063600,
  "type": "refresh"
}
```

### 权限模型（RBAC - 角色基访问控制）

#### 三层权限系统

```
用户 (User)
  ↓
分配角色 (Role)
  ├─ Admin      (管理员 - 所有权限)
  ├─ User       (普通用户 - 基础权限)
  └─ Guest      (访客 - 只读权限)
  ↓
角色包含权限 (Permission)
  ├─ read:documents
  ├─ write:documents
  ├─ delete:documents
  ├─ manage:users
  └─ ...
```

#### 数据库表关系

```
users (用户表)
  ├─ id (主键)
  ├─ username
  ├─ email
  ├─ hashed_password
  ├─ status (active/suspended/deleted)
  └─ role (admin/user/guest)
       ↓
user_role_assignments (用户角色分配)
  ├─ user_id
  ├─ role
  └─ assigned_at
       ↓
user_permissions (用户权限)
  ├─ user_id
  ├─ permission (字符串形式)
  └─ created_at
```

## 🛠️ 实现认证授权的关键步骤

### 步骤 1: 密码安全处理

```python
# 密码哈希 (用于注册和密码修改)
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

# 哈希密码
hashed = pwd_context.hash("user_password")

# 验证密码
is_correct = pwd_context.verify("user_password", hashed)
```

**关键点**:

- ✅ 使用 bcrypt（不要用 md5、sha1）
- ✅ 使用随机 salt
- ✅ 密码最少 8 个字符
- ✅ 要求大小写字母和数字

### 步骤 2: JWT Token 生成与验证

```python
# JWT 生成
from jose import jwt
from datetime import datetime, timedelta

SECRET_KEY = "your-super-secret-key-change-in-production"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30

def create_access_token(data: dict, expires_delta: timedelta = None):
    to_encode = data.copy()

    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)

    to_encode.update({"exp": expire})
    encoded_jwt = jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
    return encoded_jwt

# JWT 验证
def verify_token(token: str):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        user_id = payload.get("sub")
        if user_id is None:
            return None
        return user_id
    except:
        return None
```

**关键点**:

- ✅ 在生产环境使用强密钥（至少 32 个随机字符）
- ✅ 使用 HS256 或 RS256 算法
- ✅ 设置合理的过期时间
- ✅ 验证失败时返回 401 Unauthorized

### 步骤 3: 用户注册 API

```python
@app.post("/api/auth/register")
def register(username: str, email: str, password: str, full_name: str):
    # 1. 检查用户是否已存在
    if db.query(User).filter(User.username == username).first():
        raise HTTPException(status_code=400, detail="用户名已存在")

    # 2. 检查邮箱是否已注册
    if db.query(User).filter(User.email == email).first():
        raise HTTPException(status_code=400, detail="邮箱已被注册")

    # 3. 验证密码强度
    if len(password) < 8:
        raise HTTPException(status_code=400, detail="密码至少 8 个字符")

    # 4. 哈希密码
    hashed_password = pwd_context.hash(password)

    # 5. 创建用户记录
    user = User(
        username=username,
        email=email,
        hashed_password=hashed_password,
        full_name=full_name,
        role="user",  # 默认角色
        status="active"
    )
    db.add(user)
    db.commit()

    return {"message": "注册成功", "user_id": user.id}
```

### 步骤 4: 用户登录 API

```python
@app.post("/api/auth/login")
def login(username: str, password: str):
    # 1. 查询用户
    user = db.query(User).filter(User.username == username).first()
    if not user:
        raise HTTPException(status_code=401, detail="用户名或密码错误")

    # 2. 验证密码
    if not pwd_context.verify(password, user.hashed_password):
        raise HTTPException(status_code=401, detail="用户名或密码错误")

    # 3. 检查用户状态
    if user.status != "active":
        raise HTTPException(status_code=403, detail="用户账户已被禁用")

    # 4. 更新最后登录时间
    user.last_login_at = datetime.utcnow()
    db.commit()

    # 5. 生成 tokens
    access_token = create_access_token(data={"sub": user.id, "username": user.username})
    refresh_token = create_access_token(
        data={"sub": user.id, "type": "refresh"},
        expires_delta=timedelta(days=7)
    )

    # 6. 保存会话到数据库
    session = UserSession(
        user_id=user.id,
        access_token=access_token,
        refresh_token=refresh_token,
        expires_at=datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    )
    db.add(session)
    db.commit()

    return {
        "access_token": access_token,
        "refresh_token": refresh_token,
        "token_type": "Bearer",
        "expires_in": ACCESS_TOKEN_EXPIRE_MINUTES * 60
    }
```

### 步骤 5: Token 验证中间件

```python
from fastapi.security import HTTPBearer, HTTPAuthenticationCredentials

security = HTTPBearer()

async def get_current_user(
    credentials: HTTPAuthenticationCredentials = Depends(security)
):
    token = credentials.credentials

    # 验证 token
    user_id = verify_token(token)
    if not user_id:
        raise HTTPException(status_code=401, detail="Token 无效或已过期")

    # 查询用户
    user = db.query(User).filter(User.id == user_id).first()
    if not user:
        raise HTTPException(status_code=401, detail="用户不存在")

    return user

# 在需要认证的 API 上使用
@app.get("/api/users/me")
def get_current_user_info(current_user: User = Depends(get_current_user)):
    return {
        "id": current_user.id,
        "username": current_user.username,
        "email": current_user.email,
        "role": current_user.role
    }
```

### 步骤 6: 权限验证装饰器

```python
def require_role(role: str):
    async def check_role(current_user: User = Depends(get_current_user)):
        if current_user.role != role and current_user.role != "admin":
            raise HTTPException(status_code=403, detail="权限不足")
        return current_user
    return check_role

def require_permission(permission: str):
    async def check_permission(current_user: User = Depends(get_current_user)):
        if current_user.role == "admin":  # 管理员拥有所有权限
            return current_user

        # 检查用户是否拥有该权限
        has_perm = db.query(UserPermission).filter(
            UserPermission.user_id == current_user.id,
            UserPermission.permission == permission
        ).first()

        if not has_perm:
            raise HTTPException(status_code=403, detail=f"缺少权限: {permission}")

        return current_user
    return check_permission

# 使用示例
@app.delete("/api/users/{user_id}")
def delete_user(
    user_id: str,
    current_user: User = Depends(require_role("admin"))  # 仅管理员
):
    # ... 删除用户逻辑
    return {"message": "用户已删除"}

@app.post("/api/documents")
def create_document(
    current_user: User = Depends(require_permission("write:documents"))
):
    # ... 创建文档逻辑
    return {"message": "文档已创建"}
```

### 步骤 7: Token 刷新 API

```python
@app.post("/api/auth/refresh")
def refresh_token(refresh_token: str):
    # 验证刷新令牌
    user_id = verify_token(refresh_token)
    if not user_id:
        raise HTTPException(status_code=401, detail="刷新令牌无效")

    # 查询用户
    user = db.query(User).filter(User.id == user_id).first()
    if not user:
        raise HTTPException(status_code=401, detail="用户不存在")

    # 生成新的访问令牌
    new_access_token = create_access_token(
        data={"sub": user.id, "username": user.username}
    )

    return {
        "access_token": new_access_token,
        "refresh_token": refresh_token,
        "token_type": "Bearer",
        "expires_in": ACCESS_TOKEN_EXPIRE_MINUTES * 60
    }
```

## 📝 前端集成指南（React）

### 登录流程

```typescript
// api/auth.ts
async function login(username: string, password: string) {
  const response = await fetch('/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username, password }),
  });

  const data = await response.json();
  if (response.ok) {
    localStorage.setItem('access_token', data.access_token);
    localStorage.setItem('refresh_token', data.refresh_token);
    return data;
  } else {
    throw new Error(data.detail);
  }
}

// api/request.ts - 自动添加 Token
function apiRequest(url: string, options: RequestInit = {}) {
  const token = localStorage.getItem('access_token');

  return fetch(url, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      ...options.headers,
      ...(token && { 'Authorization': `Bearer ${token}` }),
    },
  }).then(async (res) => {
    // 如果返回 401，尝试刷新 token
    if (res.status === 401) {
      const refreshToken = localStorage.getItem('refresh_token');
      if (refreshToken) {
        const newTokens = await refreshAccessToken(refreshToken);
        localStorage.setItem('access_token', newTokens.access_token);

        // 重试原请求
        return apiRequest(url, options);
      } else {
        // 无法刷新，需要重新登录
        window.location.href = '/login';
        throw new Error('Session expired');
      }
    }
    return res.json();
  });
}

// 权限路由
const ProtectedRoute = ({ element, requiredRole }: Props) => {
  const user = useAuth();

  if (!user) {
    return <Navigate to="/login" />;
  }

  if (requiredRole && user.role !== requiredRole && user.role !== 'admin') {
    return <Navigate to="/403" />;
  }

  return element;
};
```

## 🔒 安全最佳实践

### 1. 密钥管理

❌ 不要做

```python
JWT_SECRET_KEY = "secret"  # 太简单
```

✅ 要做

```python
import secrets
JWT_SECRET_KEY = secrets.token_urlsafe(32)  # 生成强密钥

# 或在生产环境从环境变量读取
import os
JWT_SECRET_KEY = os.getenv("JWT_SECRET_KEY")
```

### 2. 生成强密钥

```bash
# Python
python -c "import secrets; print(secrets.token_urlsafe(32))"

# Linux/Mac
openssl rand -base64 32

# PowerShell
[System.Convert]::ToBase64String([System.Security.Cryptography.RNGCryptoServiceProvider]::new().GetBytes(32))
```

### 3. CORS 配置

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],  # 只允许前端域名
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "DELETE"],
    allow_headers=["Content-Type", "Authorization"],
)
```

### 4. HTTPS 配置（生产环境）

```nginx
server {
    listen 443 ssl http2;
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://backend:8000;
        proxy_set_header Authorization $http_authorization;
    }
}
```
