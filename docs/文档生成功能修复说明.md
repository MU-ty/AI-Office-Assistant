# 文档生成功能修复说明

## 问题描述
前端无法使用文档生成功能，用户无法下载会议纪要的 PDF、Word 或 Markdown 格式。

## 根本原因分析

### 1. **后端缺少依赖包** ❌
- 缺少 `reportlab` (PDF生成)
- 缺少 `python-docx` (Word文档生成)

### 2. **前端缺少API调用** ❌
- 前端 `api.ts` 没有导出/下载相关的函数
- UI 没有提供下载按钮

### 3. **静态文件服务未配置** ❌
- 后端未配置 `/uploads` 路径的静态文件访问

### 4. **导出函数返回值问题** ⚠️
- `export_minutes` 返回的文件路径格式不适合前端下载

## 修复内容

### 1. 后端依赖包安装

**文件**: `backend/pyproject.toml`

```toml
# 文档生成
reportlab = ">=4.0.0"
python-docx = ">=1.1.0"
```

**操作**: 需要重新安装依赖
```bash
cd backend
pip install reportlab python-docx
# 或者如果使用 poetry/pip-tools
pip install -e .
```

### 2. 前端 API 函数添加

**文件**: `frontend/src/modules/meeting/api.ts`

添加了三个新函数：
- `exportMeetingMinutes()` - 调用后端导出API
- `downloadMeetingMinutes()` - 处理文件下载逻辑
- 支持三种格式：markdown、pdf、docx

### 3. 前端 UI 更新

**文件**: `frontend/src/modules/meeting/index.tsx`

添加了：
- 导入 `Download` 图标和 `downloadMeetingMinutes` 函数
- `handleDownload()` 函数处理下载逻辑
- 底部工具栏显示三个下载按钮（Markdown、PDF、Word）
- 下载状态提示

### 4. 后端导出函数重构

**文件**: `backend/app/services/meeting_minutes_service.py`

`export_minutes()` 函数改进：
- **Markdown**: 直接返回内容字符串
- **PDF/DOCX**: 生成文件并返回可访问的URL路径
- 错误处理优化

返回格式：
```python
{
    "meeting_id": "...",
    "format": "pdf",
    "file_path": "/uploads/meeting_xxx_minutes.pdf",  # 可访问的URL
    "filename": "meeting_xxx_minutes.pdf"
}
```

### 5. 静态文件服务配置

**文件**: `backend/app/main.py`

添加了：
```python
from fastapi.staticfiles import StaticFiles
import os

# 确保上传目录存在
if not os.path.exists(settings.UPLOAD_DIR):
    os.makedirs(settings.UPLOAD_DIR)

# 挂载静态文件服务
app.mount("/uploads", StaticFiles(directory=settings.UPLOAD_DIR), name="uploads")
```

## 使用方法

### 前端使用

1. 完成会议音频处理后，在底部工具栏会显示导出按钮
2. 点击对应格式按钮即可下载：
   - **Markdown**: 直接下载当前显示内容
   - **PDF**: 调用后端生成专业PDF文档
   - **Word**: 调用后端生成可编辑的Word文档

### API 端点

```
POST /api/v1/meetings/{meeting_id}/export?format=markdown|pdf|docx
```

**请求参数**:
- `meeting_id`: 会议ID
- `format`: 导出格式 (markdown/pdf/docx)

**响应示例 (PDF/DOCX)**:
```json
{
  "meeting_id": "meeting_1769567947",
  "format": "pdf",
  "file_path": "/uploads/meeting_1769567947_minutes.pdf",
  "filename": "meeting_1769567947_minutes.pdf"
}
```

**响应示例 (Markdown)**:
```json
{
  "meeting_id": "meeting_1769567947",
  "format": "markdown",
  "content": "# 会议纪要\n\n...",
  "filename": "meeting_1769567947_minutes.md"
}
```

## 注意事项

### PDF 生成注意事项
- 需要系统安装中文字体（如 SimHei）
- Windows: `C:\Windows\Fonts\simhei.ttf`
- Linux/Mac: 需要安装中文字体包

### CORS 配置
确保 `backend/app/core/config.py` 中的 CORS 设置允许前端域名：
```python
CORS_ORIGINS = ["http://localhost:3000", "http://localhost:8080"]
```

### 文件路径
- 所有生成的文件保存在 `backend/uploads/` 目录
- 文件命名格式: `meeting_{meeting_id}_minutes.{format}`
- 静态文件通过 `/uploads/` 路径访问
